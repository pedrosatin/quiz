# Logo Quiz

A single-page brand-logo quiz. Pick a category, answer ten multiple-choice questions against a 15-second timer per question, and check your accuracy afterward on a dashboard.

## How it works

- The home screen shows a grid of categories with your progress for the current cycle.
- Starting a round loads ten questions from logos you haven't seen yet in that category's cycle (once you've seen every logo, the cycle resets).
- Each question shows a brand's logo and four name options; you answer by clicking or with keys 1–4.
- After ten questions, the results screen shows your score and a per-question breakdown, with options to replay the category or pick a new one.
- The dashboard aggregates accuracy, response time, and most-missed logos across all your sessions.

There's no backend: session state lives in memory (Zustand) while a round is in progress, and progress/analytics/settings persist to `localStorage` on this browser only.

## Stack

- React 19 + TypeScript, built with Vite
- Tailwind CSS v3 for styling, dark mode via a `dark` class on `<html>`
- Zustand for in-round session state
- React Router v7 for routing (`/`, `/quiz?category={slug}`, `/results`, `/dashboard`)
- Static JSON data in `public/data/`, fetched at runtime rather than bundled

## Running it

```sh
npm install
npm run dev
```

Other scripts:

```sh
npm run build            # tsc -b && vite build
npm run preview          # serve the production build locally
npm run generate-colors  # regenerate public/data/brandColors.json from simple-icons
npx tsc --noEmit         # type-check
```

There is currently no configured test runner or lint script; `npx tsc --noEmit` and `npm run build` are the available checks.

## Data

- `public/data/logos.json`: 464 brands across 10 categories, with fields like `id`, `name`, `category`, `imageUrl`, `simpleIconsSlug`, `difficulty`, `yearFounded`, and `country`.
- `public/data/brandColors.json`: generated by `scripts/generate-brand-colors.js`, mapping each brand slug to its hex color.
- `public/logos/*.svg`: monochrome logo files, rendered white over each brand's color as background.

Categories: Food, Fashion & Sports; Cars & Motors; E-commerce & Retail; Finance & Crypto; Games & Esports; Mobility, Travel & Transport; Social Media & Communication; Software & Dev Tools; Streaming & Entertainment; Technology & Hardware.

The brand logo SVGs come from [Simple Icons](https://simpleicons.org/) (CC0-licensed) via the `simple-icons` npm package.

## Project structure

```
src/
  pages/      HomePage, QuizPage, ResultsPage, DashboardPage — own routing and navigation
  components/ presentational, callback-driven UI (ErrorBoundary and friends)
  hooks/      useQuiz, useProgress, useAnalytics, useTheme
  store/      quizStore.ts (Zustand session state)
  utils/      dataLoader, formatters, localStorage, nanoid, shuffleArray
  types/      shared TypeScript types
```

`docs/architecture.md` documents routes, components, hooks, and store actions in more detail. `docs/localstorage.md` documents the persisted storage schema (`quiz_analytics`, `quiz_progress_{categorySlug}`, `quiz_settings`).
